# UniTime Demo Video Script

**Target length:** about 2 minutes 52 seconds  
**Format:** record the app running on an emulator or Android phone. The bracketed directions are for the team; they are not spoken.

## 0:00–0:25 — Problem and pitch

*[Show the Today screen, then open Week.]*

**Speaker 1:** “When class details are spread across messages, notes, and memory, it can be hard to check what’s next or keep track of a changed time or room. UniTime is a simple weekly timetable for university and college students in Zambia, built around each student’s own classes.”

## 0:25–0:43 — Show the timetable

*[Scroll through Week.]*

**Speaker 2:** “Today shows classes scheduled for the current day. Week organizes the full timetable by weekday. Let’s add a class and see how it works.”

## 0:43–1:17 — Add a class

*[Tap Add class. Enter “Mobile App Development,” choose Monday, set 09:00–10:30, enter “Lab 2,” then tap Save.]*

**Speaker 2:** “I enter the class name, weekday, start and end times, and an optional venue. UniTime checks the required details and makes sure the end time is after the start time before saving.”

## 1:17–1:40 — Show the saved entry

*[Show the entry under Monday. Tap it to show the edit screen, then return to Week.]*

**Speaker 3:** “The class is now in the timetable. We can tap an entry to edit or delete it, and UniTime flags overlapping classes so the student can review them.”

## 1:40–2:20 — Researched concept: Room

*[Close and reopen the app, then return to Week to show the saved entry.]*

**Speaker 4:** “One concept we taught ourselves was Android Room, which stores structured data in a local database. In UniTime, each class is saved as a record with its day, times, and venue. A DAO provides the operations to read, add, or delete those records, while the screen observes the updated list. After reopening the app, the saved class is still here, and the timetable works offline.”

## 2:20–2:42 — Optional reminders

*[Open Settings and show the reminder options.]*

**Speaker 4:** “Reminders are optional. In Settings, students can choose 5, 15, or 30 minutes before class. We used Android’s notification permission and WorkManager to schedule background reminders. Android may delay delivery, and the timetable still works if permission is denied.”

## 2:42–2:52 — Close

**Speaker 5:** “UniTime focuses on one practical job: helping students manage their own weekly class schedule. Thanks for watching.”

## Recording notes

- One person can narrate all the lines while another operates the emulator, or the team can divide the speaker parts.
- Keep the final video under 3 minutes.
- Upload it to YouTube as **Unlisted** and check that the submitted link works.
